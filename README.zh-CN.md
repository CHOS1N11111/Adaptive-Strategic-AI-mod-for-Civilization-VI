# Adaptive Strategic AI

面向《文明 VI：风云变幻》的 AI 重做 Mod，目标是让神级对局从开局到胜利阶段都保持竞争压力。

**版本 0.11.13** | **需要风云变幻** | **以神级为主要目标** | **建议新开游戏**

原版神级把大量难度集中在开局，AI 到中后期却经常失去压力。本 Mod 降低部分开局堆叠，并用随时代增长的难度曲线和逐 AI 自适应控制，帮助 AI 把经济、军力与胜利路线真正转化为结果。

> **玩家体验：** AI 可以领先、恢复、防守、进攻并完成胜利。强势 AI 会保留优势；只有明显落后的 AI 才会得到有边界的扶持。Mod 不会要求所有 AI 每回合都与玩家分数相同。

## 主要特点

- **整局都有竞争。** 神级前期仍有威胁，经济、战斗与经验奖励会随世界时代增长，避免中后期过早失去压力。
- **每个 AI 独立调整。** 所有主要 AI 都会比较自身与玩家、世界整体及自身近期趋势，并根据局势在发展、恢复、扩张、防御、施压和战争计划之间调整。
- **更有效的扩张与经济。** 科研补救衔接前置科技与科研建筑；贸易补救区分缺容量和缺商人，分别控制预算，并按需提高商人生产专门化优先级。相对扩张在工业时代转为有条件执行、现代时代停止；开拓者闲置或城市转为自由城市时，会暂缓继续扩张。
- **更可信的军事行为。** 补军依据实际陆军、远程与攻城缺口及已有排产。持续防御失败会加强陆军优先级，但不会无限期阻断经济补救。复盘区分局部恢复与安全恢复，也区分己方仍持有的占领或有效掠夺与敌方全局损失。
- **更好的胜利转化。** 科技执行衔接火箭学、首港、卫星、后续里程碑与激光项目。首港预算考虑有候选资格的高产城市，并允许有限的更快替补。安全的科技冲刺可在复盘认定的低收益战争中降低普通扩军优先级；新威胁或新的战争收益会解除让产限制。
- **有限恢复，而非强行同分。** 单项不足只调整决策；只有广泛或严重落后才获得可逆的产出扶持，匹配或领先的 AI 不会受到玩家相对削弱。

本 Mod **不会**直接生成单位，也不会赠送科技、市政、资源、城市或已累计进度。

排产预算控制额外优先级，并非单位或区域的硬性数量限制。合法地块和生产订单仍由原生 AI 决定，原生策略刷新也可能晚于 Mod 条件变化。

## 自适应扶持

自适应扶持只影响之后的 AI 决策和产出，不会改写已经完成的进度。

| AI 状态 | 神级下的处理 |
| --- | --- |
| 科技、文化或帝国仅一项较弱 | 只调整对应优先级，不增加全局产出 |
| 确认出现广泛落后 | `+20%` 生产、`+15%` 科技/文化、`+10%` 粮食 |
| 确认进入严重崩塌 | 用 `+40%` 生产、`+30%` 科技/文化、`+20%` 粮食取代轻度档 |
| 与玩家匹配或领先 | 不提供自适应产出，也不施加玩家相对惩罚 |

扶持需要连续确认，具有退出线和冷却时间；AI 恢复后会通过精确反向倍率完整撤销。

## 神级难度曲线

下表是 Mod 替换原版数值后，神级 AI 获得的总奖励：

| 世界时代 | 生产/金币 | 科技/文化/信仰 | 战斗力 | 单位经验 |
| --- | ---: | ---: | ---: | ---: |
| 远古 | +50% | +24% | +3 | +30% |
| 古典 | +55% | +27% | +3 | +32% |
| 中世纪 | +65% | +32% | +4 | +34% |
| 文艺复兴 | +75% | +38% | +5 | +36% |
| 工业 | +85% | +45% | +5 | +38% |
| 现代 | +95% | +52% | +5 | +40% |
| 原子能 | +105% | +60% | +5 | +40% |
| 信息/未来 | +115% | +60% | +5 | +40% |

远古时代开局时，神级 AI 总计拥有 2 个开拓者、3 个勇士和 1 个建造者。这个开局低于原版神级，让玩家前期的决策仍有实际意义。

## 安装

1. 下载或克隆本仓库到《文明 VI》的 `Mods` 目录。
2. 确认 `AdaptiveStrategicAI.modinfo` 直接位于下载后的 Mod 文件夹内。
3. 在游戏中进入“额外内容 -> 模组”，启用 **Adaptive Strategic AI**。
4. 选择“风云变幻”规则集并新建游戏。

Windows 默认路径：

```text
%USERPROFILE%\Documents\My Games\Sid Meier's Civilization VI\Mods
```

目前主要测试组合是神级、标准速度、远古时代开局。时间判断会按游戏速度换算，但其他组合的测试较少。把 Mod 中途加入旧存档无法重建开局单位或已经错过的难度阶段。

## 兼容性

不要与 RHAI、Real Strategy、AI+、Better AI Tweaks、Late Game AI、Smoother Difficulty，以及其他重写 AI 策略或难度奖励的 Mod 同时启用。

纯 UI Mod 通常可以共存。Better Balanced Game 会大幅修改科技、单位与区域，因此不保证兼容。当前测试以单人模式为主；Mod 元数据声明支持多人模式，但多人测试覆盖少于单人模式。

## 配置与问题反馈

普通玩家不需要修改配置。节奏和诊断参数位于 [`AI/10_CoreEconomy.sql`](AI/10_CoreEconomy.sql)，执行补救阈值位于 [`AI/25_ExecutionRecovery.sql`](AI/25_ExecutionRecovery.sql)。指标日志默认开启；独立的只读 UI 模块会在 `Lua.log` 中补充实际商路、文化伟人点及城市生产记录。

提交问题时，请在 [GitHub Issues](https://github.com/CHOS1N11111/Adaptive-Strategic-AI-mod-for-Civilization-VI/issues) 中附上 Mod 版本、游戏设置、启用的 Mod 列表，以及相关的 `Database.log`、`Modding.log` 和 `Lua.log`。

仓库一致性检查：

```powershell
python .\Tools\validate_mod.py
```

行为回归测试需要本机 Lua 5.3/5.4：`python .\Tools\run_lua_tests.py --lua lua`。
